# EverXCloud

EverXCloud is a US spot exchange for renting cloud GPUs by the hour.

- Live GPU market: https://everxcloud.ai/en/market
- GPU models and specs: https://everxcloud.ai/en/gpu
- GPU comparisons: https://everxcloud.ai/en/compare
- GPU and AI glossary: https://everxcloud.ai/en/glossary
- Developer docs (REST API, scoped keys, signed webhooks): https://everxcloud.ai/en/developers

Buy GPU hours at the market price, or place a bid and get matched when an offer meets it.
Prepaid accounts, prices per GPU-hour excluding tax.
